# Dataset

`GoCJ_Dataset_300.txt` = 300 task, satu angka panjang task (MI) per baris.
Sumber: GoCJ (Google Cloud Jobs) - Hussain & Aleem (2018), *Data* 3(4):38, doi.org/10.3390/data3040038. Diunduh dari Mendeley Data.
Cek lisensi di halaman Mendeley Data sebelum dipublikasikan ke repo publik.

Ringkasan: n=300, min=15.000, max=900.000, rata-rata=138.420, total=41.526.000 MI.
Jangan diubah. Kalau mengganti dataset, catat di README utama dan jalankan ulang semua hasil di `results/`.
`tools/make_dummy_gocj.py` hanya untuk data uji (BUKAN untuk hasil final).
